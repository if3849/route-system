Amazon 구매 진행

✅ 결재 완료 — Amazon 결제 진행하세요

결재가 승인되어 PO 번호가 발급되었습니다.
아래 버튼을 누르면 PO가 클립보드에 복사되고 Amazon이 열립니다.
📦 Purchase Order Number
—
↑ Amazon 체크아웃의 "Purchase Order Number" 칸에 위 번호를 입력하세요.
PO 번호 없이는 결제가 차단됩니다.
✓ PO가 클립보드에 복사되었습니다.
✓ 결제 완료 후 실제 금액 입력
Amazon 체크아웃에서 본 최종 결제 금액 (Tax 포함)을 입력하세요. 자산관리에 자동 반영됩니다.
$
결재 시스템 열기 →
1. 위 버튼 클릭 → 클립보드 복사 + Amazon 열림
2. Amazon 장바구니 → Proceed to Checkout
3. "Purchase Order Number" 칸에서 Ctrl+V (또는 ⌘+V) 붙여넣기
4. Place Order → 결제 완료
5. 이 페이지로 돌아와 실제 결제액 (Tax 포함) 입력 → 자산관리 자동 반영
